이번 세션을 돌아보고 HANDOFF.md를 업데이트한다.

## 규칙

- HANDOFF.md를 **덮어쓴다** (누적 금지)
- 에이전트가 세션 시작 시 개발을 이어가는 데 반드시 알아야 할 정보만 기재한다
- 이미 코드에서 읽을 수 있는 정보(파일 구조, 함수명 등)는 쓰지 않는다
- 주요 개발이 없었다면 날짜만 업데이트하고 나머지는 그대로 유지한다
- 간결하게 — 섹션당 5줄 이내를 목표로 한다

## 포함할 내용 (필요한 경우에만)

- 시스템 구조 다이어그램 (폴더/포트 변경 시)
- 에이전트 역할과 트리거 조건 (변경 시)
- 현재 웹 UI 동작 방식 중 코드만 봐서는 파악하기 어려운 부분
- 알려진 버그 또는 임시 처리된 로직
- 실행 방법 (변경 시)
- GitHub 레포 URL

## 제외할 내용

- 변경 이력 / 작업 로그
- 코드에서 자명한 정보
- 계획이나 논의 중인 사항 (결정된 사항만)

## 절차

1. 현재 HANDOFF.md를 읽는다
2. 이번 세션에서 개발적으로 중요한 변경이 있었는지 판단한다
3. 있었다면 해당 내용을 반영해 전체를 새로 작성한다
4. 없었다면 `마지막 업데이트` 날짜만 오늘로 바꾼다
5. 오늘 날짜: 파일 작성 시점의 실제 날짜를 사용한다
